# DataToColor 数据字段映射表

> 从 DataToColor.lua 分析得出的所有数据字段(108个像素帧)

## 📊 字段清单 (按像素索引)

### 基础信息 (0-9)
- **0**: 初始化标志 (0 = 正常模式)
- **1**: 玩家X坐标 (float * 10)
- **2**: 玩家Y坐标 (float * 10)
- **3**: 玩家朝向角度 (GetPlayerFacing)
- **4**: 地图ID (MapUIId)
- **5**: 玩家等级
- **6**: 尸体X坐标 (float * 10)
- **7**: 尸体Y坐标 (float * 10)
- **8**: 布尔标志位1 (Bits1)
- **9**: 布尔标志位2 (Bits2)

### 玩家属性 (10-15)
- **10**: 玩家最大生命值
- **11**: 玩家当前生命值
- **12**: 玩家最大能量值 (法力/怒气/能量)
- **13**: 玩家当前能量值
- **14**: 玩家最大法力值 OR 符文数量(死骑)
- **15**: 玩家当前法力值 OR 符文类型详情(死骑)

### 目标信息 (16-19, 43, 56-59)
- **16**: 目标名称前3字符 (编码)
- **17**: 目标名称后3字符 (编码)
- **18**: 目标最大生命值
- **19**: 目标当前生命值
- **43**: 目标等级 + 分类 (normal/elite/rare等)
- **56**: 目标NPC ID
- **57**: 目标GUID
- **58**: 目标正在施法的法术ID
- **59**: 鼠标悬停目标 + 目标的目标

### 背包系统 (20-24, 44-45)
- **20**: 背包信息 (类型+索引+空闲槽位+总槽位)
- **21**: 背包物品槽位 (背包号+槽位号+数量)
- **22**: 背包物品ID
- **23**: 装备槽位号
- **24**: 装备物品ID
- **44**: 金钱(铜币部分, % 1000000)
- **45**: 金钱(金币部分, / 1000000)

### 动作条状态 (25-37)
- **25-29**: 动作条按钮当前状态 (isCurrentAction, 5组x24按钮)
- **30-34**: 动作条按钮可用性 (isActionUseable, 5组x24按钮)
- **35**: 动作条消耗元数据
- **36**: 动作条消耗值
- **37**: 动作条冷却 (槽位*100000 + 持续时间*10)

### 宠物信息 (38-39, 68-69)
- **38**: 宠物最大生命值
- **39**: 宠物当前生命值
- **68**: 宠物GUID
- **69**: 宠物目标GUID

### Buff/Debuff系统 (41-42, 55, 79-84, 91-93, 104-105)
- **41**: 玩家Buff掩码 (类相关)
- **42**: 目标Debuff掩码 (类相关)
- **55**: Buff/Debuff计数 (玩家Debuff + 玩家Buff + 目标Debuff + 目标Buff)
- **79-80**: 玩家Buff (纹理ID + 持续时间)
- **81-82**: 目标Debuff (纹理ID + 持续时间)
- **83-84**: 目标Buff (纹理ID + 持续时间)
- **91**: 焦点Buff掩码
- **92-93**: 焦点Buff (纹理ID + 持续时间)
- **104-105**: 玩家Debuff (纹理ID + 持续时间)

### 技能和施法 (40, 46-54, 60-63, 70-76, 94-95)
- **40**: 法术距离检测
- **46**: 种族ID + 职业ID + 客户端版本
- **47**: UI错误消息时间戳
- **48**: 变形形态ID (ShapeShift)
- **49**: 距离范围 (minRange-maxRange)
- **50**: 玩家当前经验值
- **51**: 玩家升级所需经验值
- **52**: 最后的UI错误消息
- **53**: 玩家正在施法的法术ID
- **54**: 装备平均耐久度*100 + 连击点/神圣能量
- **60**: 最后自动射击时间
- **61**: 最后主手近战攻击时间
- **62**: 最后施法事件时间
- **63**: 最后施法法术ID
- **70**: 施法次数计数器
- **71**: 法术书队列 (法术ID)
- **72**: 天赋队列 (天赋哈希)
- **75**: 近战攻击速度
- **76**: 剩余施法时间 (毫秒)
- **94**: 最后施法GCD
- **95**: 当前GCD剩余时间 (毫秒)

### 战斗日志 (64-67)
- **64**: 造成伤害队列
- **65**: 受到伤害队列
- **66**: 怪物死亡队列
- **67**: Miss类型队列

### 交互和对话 (73, 97-99, 101-103)
- **73**: Gossip对话队列
- **97**: 拾取物品数量 + 拾取状态
- **98**: 聊天消息数据
- **99**: 聊天消息元数据 (类型 + 长度 + 偏移)
- **101**: SoftInteract GUID
- **102**: SoftInteract NPC ID
- **103**: SoftInteract 类型

### 鼠标悬停 (85-87)
- **85**: 鼠标悬停单位等级 + 分类
- **86**: 鼠标悬停NPC ID
- **87**: 鼠标悬停GUID

### 其他信息 (74, 88-90, 96, 100, 106-107)
- **74**: 自定义触发器
- **88**: 远程伤害
- **89**: 焦点最大生命值
- **90**: 焦点当前生命值
- **96**: SpellQueueWindow + 网络延迟
- **100**: 布尔标志位3 (Bits3)
- **106**: 全局时间戳 (GLOBAL_TIME_CELL)
- **107**: 元数据/验证标志

### 焦点目标 (77-78)
- **77**: 焦点GUID
- **78**: 焦点目标GUID

## 📝 注意事项

1. **数据编码**: DataToColor使用RGB颜色编码(0-16777215范围)
2. **队列系统**: 某些数据(背包/法术书/天赋)使用队列轮询
3. **时间戳**: 使用globalTime作为全局时钟
4. **布尔位**: 使用Bits1/Bits2/Bits3打包多个布尔标志
