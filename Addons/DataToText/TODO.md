# DataToText 开发任务清单

## 项目概述
将游戏数据以 OCR 友好的文本格式显示在屏幕顶部,替代像素编码方案 (DataToColor)。

**当前状态**: 使用稳定的简化版本 (DataToText.lua + DataToText.xml)，渐进式改进中。

## 📝 技术笔记

### 当前版本架构
- **文件**: `DataToText.lua` (主逻辑) + `DataToText.xml` (UI定义)
- **字体**: Tiny-Bold.ttf, 14px, MONOCHROME
- **更新频率**: 0.1秒 (10 FPS)
- **显示内容**: 玩家数据、目标数据、背包数据

### 已知限制
- 目标名称尚未支持中文（需要 UTF-8 编码）
- 未实现完整的数据格式（只有基础信息）
- 没有模块化架构

### 下一步测试要求
每个步骤完成后需要：
1. 在游戏中 `/reload` 重载插件
2. 检查聊天框是否有 Lua 错误
3. 使用 `/dtt` 验证功能正常
4. 确认显示内容正确
